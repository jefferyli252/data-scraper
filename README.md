# About the project

Data scraping web application that displays organized data from file paths.

# How it works

Reads raw HTML or file data, converts to Pandas dataframes, and displays organized data with visuals.

# How to run the project

Without Docker compose:

`python -m streamlit run app.py`

With Docker:

`docker compose up`

To stop, run
`docker compose down`

## Dependencies

> Check if you have the following dependencies installed in your system. If not, please install them.
- Python virtual enviroment
- streamlit
- requests
- pandas
- plotly
- beautifulsoup
- lxml

- Docker Desktop
